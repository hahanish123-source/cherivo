# Hanora assets

Put built-in, non-private assets here.

Examples:
- decorative SVGs
- built-in background artwork
- icons
- public demo images

Use paths such as `/assets/example.svg` from the app.

## Do NOT put private customer media here

Files in `public/` are public web assets. Customer photos, videos and music should be uploaded to private storage (for example Supabase Storage) and served using access-controlled/signed URLs in the production version.
